# Kideos

Two React Native apps that work together:

| App | Bundle ID | Description |
|---|---|---|
| `apps/Kideos` | `com.kideos.app` | Kid-facing YouTube player — shows only parent-approved videos |
| `apps/KideosParent` | `com.kideos.parent` | Parent control app — manages channels, filters, and sessions |

**Tech stack:** React Native 0.85.3 · Firebase 11.15.0 · RNFB 22.4.0 · New Architecture enabled
